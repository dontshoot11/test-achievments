# TODO — прототип торговой платформы с userscore и ачивками

## Цель прототипа

Собрать локальное интерактивное демо для презентации руководству:

- пользователь переключается между двумя торговыми активами;
- видит график с живыми случайными тиками;
- меняет сумму и открывает сделки длительностью 5 или 10 секунд;
- каждое значимое действие попадает в журнал событий;
- за действия и ачивки начисляется userscore;
- userscore повышает уровень пользователя и меняет его аватар;
- в отдельном разделе видны открытые, закрытые и ещё не полученные ачивки.

> Прототип не подключается к реальному брокеру, рыночным данным, платежам или аккаунтам. Все данные генерируются и хранятся локально.

## Решения для первой версии

- Стек: React + TypeScript + Vite.
- Стили: CSS Modules или обычный CSS с дизайн-токенами через CSS variables.
- График: `lightweight-charts`.
- Состояние приложения: Zustand.
- Навигация: React Router.
- Иконки: Lucide React.
- Тесты: Vitest + React Testing Library.
- Данные демо сохраняются в `localStorage`, предусмотрен полный сброс прогресса.
- Два актива первой версии: BTC/USD и ETH/USD.
- Направления сделки: «Выше» и «Ниже».
- Длительность сделки: 5 или 10 секунд.
- Генератор котировок должен поддерживать фиксированный seed для воспроизводимой презентации.
