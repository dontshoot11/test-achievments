# Торговый модуль

## Зачем

Модуль реализует демо-симуляции: экран выбора набора данных и прогноза, живой свечной график, случайный запуск с предпросмотром, историю, журнал событий и popup завершённой симуляции. `store.ts` связывает баланс, прогресс, достижения и сохранение состояния в `localStorage`.

## Как пользоваться

Используйте `<TradePage />` как экран маршрута, а `<LuckyTradeModal />` и `<TradeResultModal />` смонтируйте один раз рядом с маршрутами. `PriceChart` принимает `ticks: Tick[]` и `activeTrade: Trade | null`. Состояние читайте селектором `useTradingStore`, а меняйте только действиями стора, чтобы связанные награды и записи журнала оставались согласованными.

```tsx
<Route path="/trade" element={<TradePage />} />
<LuckyTradeModal />
<TradeResultModal />
```

```ts
const prepareRandomTrade = useTradingStore((state) => state.prepareRandomTrade)
prepareRandomTrade()
```

Одновременно может выполняться только одна симуляция. Минимальная сумма — `$10`; случайный запуск выбирает направление, длительность и допустимую сумму, но начинает сделку только после подтверждения в popup. Кнопка «Редактировать» позволяет изменить все три параметра, а «Еще раз» генерирует новый набор и повторно запускает барабаны.

Случайно открытые сделки помечаются флагом `Trade.randomized`. После их завершения результат предлагает «Попробовать еще раз»: текущее окно закрывается и создаётся новый случайный черновик. Для сделок, открытых вручную, повторный случайный запуск в результате не показывается.
