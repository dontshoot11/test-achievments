# Торговый модуль

## Зачем

Модуль реализует демо-симуляции: экран выбора набора данных и прогноза, живой свечной график, случайный запуск, историю, журнал событий и popup завершённой симуляции. `store.ts` связывает баланс, прогресс, достижения и сохранение состояния в `localStorage`.

## Как пользоваться

Используйте `<TradePage />` как экран маршрута, а `<TradeResultModal />` смонтируйте один раз рядом с маршрутами. `PriceChart` принимает `ticks: Tick[]` и `activeTrade: Trade | null`. Состояние читайте селектором `useTradingStore`, а меняйте только действиями стора, чтобы связанные награды и записи журнала оставались согласованными.

```tsx
<Route path="/trade" element={<TradePage />} />
<TradeResultModal />
```

```ts
const openRandomTrade = useTradingStore((state) => state.openRandomTrade)
openRandomTrade()
```

Одновременно может выполняться только одна симуляция. Минимальная сумма — `$10`; случайный запуск выбирает набор данных, направление, длительность и допустимую сумму автоматически.
