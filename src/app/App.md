# App

## Зачем

`App` собирает постоянную оболочку демо: навигацию, профиль, маршруты, онбординг, результат симуляции и уведомления. Здесь же запускается рыночный таймер и фиксируются посещения страниц для достижений.

## Как пользоваться

Монтируйте `<App />` один раз внутри `BrowserRouter` в точке входа. Компонент не принимает пропсы и работает через `useTradingStore`; при размонтировании он останавливает свой интервал обновления рынка.

```tsx
<BrowserRouter>
  <App />
</BrowserRouter>
```
